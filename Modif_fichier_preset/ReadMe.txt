Change Presets V1.0
04/06/2024

**Run GUI.py To lancer the programme
**Need dependencies: tkinter, openpyxl, pandas

Usage:
-Read Presets:
-Presets Folder: the folder where exist the presets that we want to read.
-Export Excel folder: the folder where 	we want to save the Excel(contains Pans and Tilt of the presets).
-Excel Name: the name of the Excel.

-Change Presets:
-Excel Path: The path of the Excel who contains the data of the presets that we want to change.
-Presets Folder: the folder where exist the presets that we want to change.

!!Attention: 1-The name of the table in the Excel need to be the same as the presets( xml files ) that we want to change.
	      See PresetTest.xlsx for the example.
	  2-<GUI.py>, <read_excel.py> and <read_preset.py> need to be in the same folder
